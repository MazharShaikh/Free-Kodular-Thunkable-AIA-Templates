## Practical development checklist

### Project organization
- Give components, variables, procedures, and events meaningful names.
- Keep related logic organized and avoid duplicating the same operations unnecessarily.
- Back up projects before making significant changes.

### Data, Firebase, and APIs
- Validate user input and handle missing or malformed data.
- Handle failed network requests and empty API responses.
- Apply appropriate Firebase security rules; never publish private credentials, tokens, or API keys.
- Test offline behavior when an app uses local caching.

### Extensions and builds
- Check extension and component compatibility with your platform and project version.
- Read the full build error and isolate the component or dependency involved.
- Test changes in a copy of the project before modifying the original.

### Performance and user experience
- Avoid unnecessary repeated work in frequently triggered events.
- Optimize large assets and test on real devices.
- Make loading, error, and offline states clear to users.
